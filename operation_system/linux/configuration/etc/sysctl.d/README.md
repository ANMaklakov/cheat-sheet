# sysctl

***sysctl - инструмент для просмотра и изменения параметров ядра на лету и применения их так же после перезагрузки***  

**Оглавление:**  
* [Синтаксис](#Синтаксис)
* [Применение настроек](#Применение-настроек)
* [Примеры параметров](#Примеры-параметров)

# Синтаксис

```
ПАРАМЕТР=ЗНАЧЕНИЕ
```

- **Знак '-' перед параметром означает использование мягкой установки.**  
**Параметр применится если он существует, в случае отутствия параметр будет проигнорирован без ошибки (например ядро старое и не поддерживает параметр)**  
```
-net.core.default_qdisc=fq_codel
```
