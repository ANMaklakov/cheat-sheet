# sysctl

***sysctl - инструмент для просмотра и изменения параметров ядра на лету и применения их так же после перезагрузки***  

**Оглавление:**  
* [Синтаксис](#Синтаксис)
* [Применение настроек](#Применение-настроек)

# Синтаксис

```
ПАРАМЕТР=ЗНАЧЕНИЕ
```

- **Знак '-' означает использование мягкой установки, т.е. применение если параметр существует, но в случае отутствия игнорировать без ошибки (например ядро старое и не поддерживает параметр)**  
```
-net.core.default_qdisc=fq_codel
```
