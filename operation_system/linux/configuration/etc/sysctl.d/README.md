# Основные файлы и директории

📄 /etc/sysctl.conf - основной файл конфигурации параметров ядра, который применяется с помощью команды sysctl либо автоматически при загрузке системы

📁 /etc/sysctl.d/*.conf - дополнительная директория содержащая конфигурационные файлы

📁 /run/sysctl.d/*.conf - дополнительная директория для временных окружений (liveOS, PXE-boot, etc)

📁 /usr/lib/sysctl.d/*.conf - дополнительная директория для хранения конфигов базовой системы и установленного ПО

# Синтаксис

```
ПАРАМЕТР=ЗНАЧЕНИЕ
```

- **Знак '-' перед параметром означает использование мягкой установки.**  
**Параметр применится если он существует, а в случае отутствия параметр будет проигнорирован без ошибки (например ядро старое и не поддерживает параметр)**  
```
-net.core.default_qdisc=fq_codel
```

# Приоритет применения sysctl-конфигураций
* /usr/lib/sysctl.d/*.conf — базовые настройки системы
* /run/sysctl.d/*.conf — временные настройки
* /etc/sysctl.d/*.conf — настройки администратора
* /etc/sysctl.conf — в последнюю очередь
