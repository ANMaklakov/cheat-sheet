# Регулярное выражение проверки пароля

```
^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*#?&])[A-Za-z\d@$!#%*?&]{8,}$
```

Подробная расшифровка
Часть выражения	Назначение
^	Начало строки.
(?=.*[a-z])	Positive Lookahead: в строке должна быть хотя бы одна строчная латинская буква (a–z).
(?=.*[A-Z])	Positive Lookahead: в строке должна быть хотя бы одна заглавная латинская буква (A–Z).
(?=.*\d)	Positive Lookahead: в строке должна быть хотя бы одна цифра (0–9).
(?=.*[@$!%*#?&])	Positive Lookahead: в строке должен быть хотя бы один специальный символ из набора @$!%*#?&.
[A-Za-z\d@$!#%*?&]{8,}	Основной шаблон: строка должна состоять только из символов, разрешённых в пароле (буквы латинского алфавита, цифры и спецсимволы из списка) и иметь длину не менее 8 символов.
$	Конец строки.



🔹 Блоки Positive Lookahead: (?=...)

Это конструкция, называемая положительным просмотром вперёд (positive lookahead). Она говорит:

    «Продолжай только если где-то далее по строке (начиная с текущей позиции) выполняется определённое условие».

Она не захватывает символы, а только проверяет наличие.
📌 1. (?=.*[a-z])

Расшифровка:

    ?= — positive lookahead: «убеждаемся, что условие внутри выполняется»

    .* — «любой набор символов, любой длины (включая 0)»

    [a-z] — «одна строчная латинская буква»

Итого:

    «Где-то в строке должна быть хотя бы одна строчная буква (a-z)».

Почему .*[a-z]?
Потому что .* позволяет двигаться по всей строке и искать a-z где угодно.
Это не говорит, что строка начинается с a-z, а что где-то она точно встретится.
📌 2. (?=.*[A-Z])

Аналогично:

    .* — любое количество любых символов

    [A-Z] — заглавная латинская буква

    «Где-то в строке должна быть хотя бы одна заглавная буква».

📌 3. (?=.*\d)

    \d — означает цифру [0-9]

    .*\d — означает: где-то есть цифра

    «Строка должна содержать хотя бы одну цифру».

📌 4. (?=.*[@$!%*#?&])

    .* — любое количество символов

    [@$!%*#?&] — один из перечисленных спецсимволов

    «Где-то в строке должен быть один из этих спецсимволов: @ $ ! % * # ? &».

🔹 Основной шаблон: [A-Za-z\d@$!#%*?&]{8,}

Этот фрагмент фактически "захватывает" строку, в отличие от (?=...).
Что здесь:

    [A-Za-z\d@$!#%*?&] — допустимые символы:

        A-Z — заглавные

        a-z — строчные

        \d — цифры (то же, что 0-9)

        @$!#%*?& — разрешенные спецсимволы

    {8,} — не менее 8 символов

    Это означает, что строка должна содержать ТОЛЬКО перечисленные символы и быть длиной не менее 8 символов.

🔹 Начало и конец строки: ^ и $

    ^ — начало строки

    $ — конец строки

Это гарантирует, что проверяется вся строка целиком, а не только часть.
🔚 Итого логика такая:

    ^ — Начинаем с начала строки

    (?=.*[a-z]) — где-то есть строчная

    (?=.*[A-Z]) — где-то есть заглавная

    (?=.*\d) — где-то есть цифра

    (?=.*[@$!%*#?&]) — где-то есть спецсимвол

    [A-Za-z\d@$!#%*?&]{8,} — строка состоит только из разрешённых символов и не короче 8

    $ — Доходим до конца строки

🔍 Почему нельзя без (?=...)?

Потому что [A-Za-z\d@$!#%*?&]{8,} просто ограничивает разрешённые символы и минимальную длину,
но не гарантирует, что все классы символов (буквы, цифры, спецсимволы) будут в строке.

Вот пример:

aaaaaaaa!1

✅ соответствует: есть строчные, есть спецсимвол, есть цифра
❌ если убрать (?=.*[A-Z]), заглавная не требуется
